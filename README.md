Job Application Tracker API

A REST API built with FastAPI to track job applications: create them, list them, update their status and delete them. Data is stored in a SQLite database.

Tech stack
Python
FastAPI
SQLModel (SQLAlchemy + Pydantic)
SQLite
pytest + FastAPI TestClient
Features
Create, list, update and delete job applications (full CRUD)
Each application has a role, company, location, salary and status
Status is validated with an Enum: In Process, Stage 1, Stage 2, Stage 3, Accepted, Declined. Any other value returns a 422 error
Separate models for incoming requests and database tables, so the id is always generated by the server
Data persists in a SQLite database across restarts
Automatic interactive documentation (Swagger UI)
Getting started

Requires Python 3.10 or newer.

bash
git clone https://github.com/sandux2/Job-Application-Tracker.git
cd Job-Application-Tracker
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
Run the API
bash
uvicorn main:app --reload

The API runs at http://127.0.0.1:8000. Interactive docs are available at http://127.0.0.1:8000/docs. The database file applications.db is created automatically on first start.

Endpoints
Method	Endpoint	Description
GET	/applications	List all applications
POST	/applications	Create a new application
PUT	/applications/{application_id}	Update the status of an application
DELETE	/applications/{application_id}	Delete an application
Example request body (POST)
json
{
  "role": "Backend Developer",
  "company": "Example Ltd",
  "location": "London",
  "salary": "45000",
  "status": "In Process"
}
Example request body (PUT)
json
{
  "status": "Stage 1"
}

An application that does not exist returns 404. An invalid status returns 422.

Run the tests
bash
pytest

The tests cover creating applications, status validation and updating the status.
